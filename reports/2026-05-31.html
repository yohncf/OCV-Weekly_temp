04 · Key findings

What the data is telling us

01

Agent Mode drafting regression (P0). Three independent users (i=34, 40, 41) report Copilot confirms reply drafts have been saved to the Drafts folder, but the drafts never appear. In one case Copilot itself admitted 'attempts to create the drafts failed again (expired) and were never saved.' One user spent 30 minutes on a single repeated draft request before filing feedback.

02

Mailbox bulk actions partial-or-no execution (P0). Three triage interactions: a folder-create-and-move returned a canned error; a copy-to-folder claimed 'I executed exactly what you requested' but the user reports nothing moved; a Copilot-categorized Low-priority mark-as-read executed on 29 of 74 emails while claiming all were cleared.

03

Calendar correctness failed at the suggestion step twice (P0 by multi-item rule). A 'go look at my calendar' surface recommended meeting times during slots the user had already booked; a true-availability request (8AM-4PM EST, ignore tentative, June 8-19) returned inaccurate dates/times.

04

Capability-refusal cluster is new this week. Six items where Copilot represented capabilities it doesn't have (persistent memory across chats, live staff calendar visibility, prior-session content recovery, action without permissions, CalendarInstructions follow-through). Four items where the agent acknowledged the gap after-the-fact (P1); three more clustered around the CalendarInstructions UX dead-end (P2). Prior week's manifest had 0 items in Topic 12.

05

Reliability error_string on informational surfaces (P1, n=4). Inbox summary, 12-month historical search, master-data pull, and a Portuguese-language email evaluation all returned canned 'Something went wrong' / 'I'm sorry, I wasn't able to process'. These are core informational capabilities.

06

Constraint-ignored is concentrated in Drafting (P1, n=5). Recipient mis-pluralization, domain-filter dropped, content truncation, missing flight-numbers in an itinerary, and no clickable links on a re-run. No single root cause.

07

Calendar Instructions UX dead-end (P2, n=3). Three items where the user followed the CalendarInstructions surface but the agent either refused, gave text-only instructions that route back to the failing Copilot pane, or could not create an auto-decline rule despite user expectation that it should be in scope.

08

Anecdotal signals worth watching but not actionable as filed (n=1 each, marked anecdotal): HitL inline-edit gap (Topic 2); Unnecessary clarification on Outlook variant (Topic 5); foreign-language injection in English response (Topic 9).

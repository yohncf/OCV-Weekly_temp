01 · TL;DR

What you need to know

  • Volume: 1,079 total submissions this week — 134 with a written comment (12.4%) and 945 thumbs-only ratings.
  • Overall sentiment is positive on raw ratings: 864 thumbs-up vs 215 thumbs-down (80.1% positive). Written comments skew negative because users self-select to type when frustrated.
  • Classified negatives: 68 verbatim items form the engineering analysis universe.
  • Top topic — Action not executed (10 items, 14.7%). Drafting/triage actions where Copilot claimed completion but state never changed. Includes a clear Agent Mode regression: drafts not landing in the Drafts folder (3 items).
  • Runner-ups: Inaccurate / fabricated content (9 items, 13.2%) and Wrong context / grounding (8 items, 11.8%).
  • New pattern — Capability refusal (6 items, 8.8%). Copilot promising memory, staff-availability, or session-continuity capabilities it doesn't actually have, then admitting the gap.

04 · Key findings

What the data is telling us

  • Most submissions are silent thumbs-up. 864 of 1079 ratings (80.1%) were positive. Only 134 users left any written comment (12.4% of all submissions). All findings below are drawn from the verbatim slice, which heavily oversamples dissatisfied users.
  • Agent Mode drafting regression (P0). Three independent users report Copilot confirms reply drafts have been saved to the Drafts folder, but the drafts never appear. In one case Copilot itself admitted 'attempts to create the drafts failed again (expired) and were never saved.'
  • Mailbox bulk actions partial-or-no execution (P0). Three triage interactions where claimed completion didn't match actual state.
  • Calendar correctness failed at the suggestion step twice (P0 by multi-item rule).
  • Capability-refusal cluster is new this week. Items where Copilot represented capabilities it doesn't have (persistent memory, staff calendar visibility, prior-session recovery), then acknowledged the gap. Prior week's manifest had 0 items in Topic 12.
  • Reliability error_string on informational surfaces (P1, n=8). Inbox summary, 12-month historical search, master-data pull, multi-language email evaluation, slash-command grounding — all returned canned errors or failed silently on informational queries.
  • Drafting constraint-ignored is concentrated (P1, n=6). Recipient mis-pluralization, format constraints dropped, content truncation, missing flight-numbers in an itinerary, no clickable links on a re-run, plain-list-vs-bulleted format ignored.
  • Calendar Instructions UX dead-end (P2, n=3). Set-up flow refuses or rule never applied; user routed in a loop.
